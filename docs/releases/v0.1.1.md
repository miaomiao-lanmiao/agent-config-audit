# Agent Config Audit 0.1.1

Date: 2026-11-18 (Asia/Shanghai).

Configuration diffs now detect changes between JSON booleans and numbers in
extension fields. Previously, changing `true` to `1` or `false` to `0` was
missed because Python treats these pairs as equal. The same issue affected
nested objects and arrays and allowed `--fail-on-change` to return 0.

These changes now appear in the `other` field category and return 1 when
`--fail-on-change` is enabled. The comparison walks containers iteratively,
preserves array order, and ignores object key order. Numerically equivalent
values such as `1` and `1.0` remain equal.

All four report formats omit extension field names and values. Regression
fixtures use synthetic data and cover both comparison directions, nested
containers, numeric equivalence, field removal, and the CLI drift gate.

Install the downloaded wheel with:

```sh
python -m pip install --no-index --no-deps agent_config_audit-0.1.1-py3-none-any.whl
```
